# PTK40A Digital Twin - Group 13 EV Charger

Interactive simulation of the Cytron PTK40A (PIC18F4550) running the Group 13
Smart EV Charging Station firmware, compiled to WebAssembly.

Open the page: https://rxzalii.github.io/ptk40a-ev-twin/

- Click the keypad: A start, B status, C report, D emergency stop, # reset
- Click GRID PEAK to toggle the grid peak (INT0) signal
- 1 real second = 1 charging minute
